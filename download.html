Download and install

What you need

  • Python 3.9 or newer, with Tk (Tk draws the window).
  • A C compiler, which builds the fast registration code. Without it the install still works, but slowly.
  • Internet for the first install: pip downloads numpy, scipy, matplotlib and imageio-ffmpeg (the last brings the program that writes MP4 videos).

You can check the download against the SHA-256 shown: certutil -hashfile er3ds.zip SHA256 on Windows, shasum -a 256 er3ds.zip on macOS, sha256sum er3ds.zip on Linux.

Install

Pick your system. You never need to “activate” the environment: the commands call the programs inside it directly.

1. Install Python and a C compiler (once)

  • Python with Tk: the installer from python.org. It includes Tk; tick “Add python.exe to PATH”.
  • C compiler: “Build Tools for Visual Studio” (free) with the “Desktop development with C++” workload. It is a large download.

Check Python and Tk: py --version, and py -c "import tkinter" must print nothing.

2. Install ER3DS

Put er3ds.zip in a folder and open a terminal there (Command Prompt or PowerShell). Then:

py -m venv er3ds-env
er3ds-env\Scripts\python -m pip install er3ds.zip
er3ds-env\Scripts\er3ds doctor
er3ds-env\Scripts\er3ds gui

The last command opens the ER3DS window. The third checks the installation (see below).

1. Install Python and a C compiler (once)

  • Python with Tk: the installer from python.org. It includes a modern Tk; the Python that comes with macOS has an old one and looks wrong. Homebrew works too: brew install python@3.12 python-tk@3.12.
  • C compiler: xcode-select --install (free, a few minutes).

Check Python and Tk: python3 --version, and python3 -c "import tkinter" must print nothing.

2. Install ER3DS

Put er3ds.zip in a folder and open a terminal there. Then:

python3 -m venv er3ds-env
er3ds-env/bin/python -m pip install er3ds.zip
er3ds-env/bin/er3ds doctor
er3ds-env/bin/er3ds gui

The last command opens the ER3DS window. The third checks the installation (see below).

1. Install Python and a C compiler (once)

sudo apt install python3 python3-venv python3-tk build-essential

Other distributions: the same three things (Python 3 with venv and Tk, and a C compiler). Check Python and Tk: python3 --version, and python3 -c "import tkinter" must print nothing.

Check that it works

Run er3ds doctor (the third command above). Under “Native C kernels” it should say status : loaded, and C vs NumPy kernels: agree.

For a longer test, er3ds selftest runs a short end-to-end analysis of both surface types on synthetic meshes and ends with RESULT: OK.

If something is not right

The doctor does not say “loaded”, or the registration is very slow

The C compiler was not found. The install still succeeded, but the slow NumPy fallback is used, and the default Praun-Hoppe parameterization is not available (the first analysis stops with a message that says so; “Tutte” works). Install the compiler (see your system above) and reinstall:

er3ds-env/bin/python -m pip install --force-reinstall --no-cache-dir er3ds.zip

On Windows use er3ds-env\Scripts\python. pip install -v er3ds.zip shows the compiler's messages if something is still wrong.

import tkinter fails or prints an error

Python was installed without Tk. On Linux install python3-tk; on Windows and macOS use the installer from python.org, which includes it.

The window looks old-fashioned on macOS

You are using the Python that comes with macOS, whose Tk is old. Install Python from python.org or with Homebrew (see the macOS tab).

Everyday use

  • The window: er3ds gui or er3ds-gui, from the er3ds-env folder as in the commands above (make a shortcut or an alias if you like). Your last choices are remembered in .er3ds_gui.json in your home folder.
  • The command line does the same without a window: er3ds --help lists the commands, and the manual has the equivalent of every tab.
  • Update: install the newer zip the same way with --upgrade: er3ds-env/bin/python -m pip install --upgrade er3ds.zip.
  • Uninstall: delete the er3ds-env folder.

On a cluster (Slurm)

A job on a cluster needs the program, not the window, so a Python without Tk is fine there. Load a Python and a compiler (on most clusters module load python gcc), create an environment and pip install er3ds.zip as above. The Slurm Job tab of the window, on the computer where you build the job, writes the job script. The manual explains it.

Without a compiler

Someone with a compiler can build a ready-made installation file (a “wheel”) once for each kind of computer with python packaging/build_wheel.py (included in the zip); the users of that file then need no compiler. A wheel works on the kind of computer it was built on.
